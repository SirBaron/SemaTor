# SemaTor 1.1.226 — public preview

Since 1.1.222:

- More room to play: Time Bandit enhancements for supported editions, with
  16:9 and 21:9 views, steadier framing on small maps and around text, and a
  fix for the early 0.96 edition's level-selection crash.
- Easier saves: new save states live in folders named after each game, with
  readable game and slot filenames. Existing saves remain loadable.
- Better adventure controls: Zak McKracken mouse input fixes and a stable
  game-specific picture setting that leaves global auto-crop unchanged.
- Less disk juggling: improved companion-disk matching, automatic changes
  for recognised requests, and a focused in-game picker for manual swaps.
- Clearer controls: updated per-game control pages and gamepad defaults for
  profiled games.
- A tidier library: revised default scale and an always-visible update
  control with a clear status, even when you're already up to date.
- More varied drive audio: loading sounds respond to disk activity with
  better use of longer recordings.

Linux x86-64 and Windows x64 desktop previews. Game compatibility and
available enhancements depend on the exact disk edition. Windows needs
broader real-machine testing. Android/Thor remain development previews.
