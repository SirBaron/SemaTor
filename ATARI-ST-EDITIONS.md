# Atari ST editions in SemaTor 1.1.619

This guide lists the Atari ST editions recognised by SemaTor 1.1.619 and the game-specific options available for each. Open **F12 → Game options** in play. The Atari ST **Keyboard Mode** control is shared across games. Entries with no game-specific options or cheats still have an edition profile. Where offered, extended gameplay is part of Widescreen.

In the library, open **Details → Verified disk names** to copy available labels. For disk sets, start with the startup disk and keep the matching companions together. Use **F4** to change disks during play when the game requests one. Compilation entries may require choosing the game from the compilation menu.

Disk filenames and edition labels help you find a copy. SemaTor checks the boot sector, program text or disk image and may also check the loaded game. The SHA-1 labels identify what was hashed. For program-text SHA-1, only the executable text is hashed. For a boot-sector SHA-1, hash the decoded 512-byte sector. A whole-image SHA-1 covers the original disk image. Recognition and menu availability can vary by build or scene.
