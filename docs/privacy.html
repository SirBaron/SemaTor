SemaTor privacy policy

Last updated: 14 November 2026

This policy covers SemaTor for Android (including the Google Play version, package org.semator.app) and the Windows and Linux desktop versions.

Files and settings

SemaTor stores your settings, library information, selected game and music files, saves, artwork and diagnostics on your device. On Android, the Play version uses app storage and Android's file and folder picker; it does not request all-files access. Files in folders you link remain subject to the access you granted Android. Clearing app data or uninstalling removes app-owned data, but exported files and content in linked folders may remain.

Connections you choose

  • Artwork: When you request cover artwork, SemaTor contacts GitHub's API and raw-content servers for the relevant artwork repository. A request can include a game title or catalogue-derived name in its URL, along with ordinary connection information such as your IP address and a SemaTor version identifier. SemaTor does not send game disk or ROM contents for artwork. GitHub handles connection data under its own policies.
  • Wi-Fi transfer: If you start a transfer and pair another SemaTor device on your local network, selected games and, optionally, their saves can be sent in either direction. The pairing code authenticates the transfer and protects its integrity, but transfer contents are not encrypted. Use this only on a trusted network and with a device you intend to pair. The receiving device stores received files locally; replacing a save can preserve the old file in a backup folder.
  • Diagnostics: Diagnostics are saved locally. If you choose to share a diagnostics file, Android opens the system share sheet so you can choose an app or recipient. That app or recipient receives the file you selected and handles it under its own policies. Do not share diagnostics unless you are comfortable disclosing their contents, which can include app/device details, settings and performance information.
  • Links and updates: Links to this site, support, compatibility reports, Discord and music services open external services. Desktop update checks contact GitHub. The Google Play build does not download or install updates itself; its update action opens Google Play.

Optional microphone recording

The Android Sample Editor can request microphone access when you choose its recording feature. Audio is used for that recording and saved locally by the app. Microphone access is not needed for music playback. If you deny permission, recording is unavailable; you can manage the permission in Android settings.

Children

SemaTor is not directed at children under 13.

Changes

If this policy changes, the new version will be published on this page with a new date.

Contact

Questions about this policy: open an issue on GitHub or ask on Discord.
