Before you start

A few useful things.

SemaTor is a desktop public preview. Every useful report helps more games and more systems work well.

Do I need a TOS ROM or bundled games?

No Atari TOS ROM is required. Bring your own game disks; no commercial game images are included. Supported formats include ST, IMG, MSA, full-sector DIM, STX and supported images inside ZIP archives.

Will every game have widescreen and enhancements?

No. These are game-specific features and depend on the exact disk edition. Check the game's enhancement page. General compatibility also varies; please report the edition you're using if something goes wrong.

What happens to my existing saves?

Existing hash-named saves remain loadable. New saves use game-named folders and readable filenames, with an edition identifier to keep different versions apart. Keep the complete User folder when moving your setup, alongside Games and Media.

How do I change a disk?

Recognised requests can select a matching companion automatically. For manual changes, open F12 → Disks, restart & exit and choose a candidate from the in-game picker. You don't need to quit back to the library.

Is there an Android or Thor release here?

Not in this desktop release. Phone and AYN Thor interfaces are still in development. The images below show earlier development work.
