FEEL THE MOTION

Smoother action.
Sharp pixels.

Dedicated smooth-motion enhancements add intermediate movement in supported games, including scrolling backgrounds in Xenon and Xenon 2. Frame generation offers another motion option; results depend on the game and settings.

Explore Xenon 2 ↗
BRING BACK THE GLOW

Your own
CRT cabinet.

Wrap the game in a CRT bezel. Tune scanlines, phosphor, glow and curvature, or choose a clean picture. Super ST colour adds smoother shading while keeping outlines sharp.

LIGHT IT UP

Auto HDR.

Give bright highlights more room to shine on a compatible HDR display. Adjust the picture to your screen with the Vulkan renderer’s HDR controls.

STAY RESPONSIVE

Run-ahead.

Predict the next game picture early to reduce the delay introduced by frame generation. SemaTor measures the cost and uses run-ahead when it fits the frame budget.

KEEP PLAYING

Save. Rewind.
Try again.

Save states with previews, rewind and per-game settings make it easier to pick up where you left off. F11 brings up your session; F12 puts the setup at your fingertips.

Enhancements are optional. Widescreen and dedicated smooth motion depend on the game and disk edition; HDR and some frame-generation options also depend on your renderer, GPU and display.

Already using SemaTor?

Use the signed in-app updater. If the older Windows interface is unreadable, extract the new ZIP over your installation, preserving Games, Media, User and Add-ons. Older updater helpers may require a full ZIP update.

What’s included—and what isn’t?

The desktop app, SemaOS and its tools are included. Supply your own game disks. No commercial games or Atari TOS ROMs are bundled. The Android testing APK is available on SemaTor Discord. It is distributed separately from these desktop downloads.

Where can I get help?

Report a problem on GitHub or join the Discord. Include the version, operating system, disk edition and steps to reproduce. Do not attach game disks or ROMs.

EXTRAS / WHEN YOU FEEL LIKE CREATING

From “one more game”
to “I made this.”

These are working apps inside SemaOS. Every screenshot below comes from the running interface, with demo content identified beneath it.

Create / SemaSynth

Three voices. A whole studio.

Compose with patterns, a song arrangement and editable instruments. Work with the ST sound chip, use a MIDI keyboard on Linux, and export your music.

Built-in Studio demo song.

  • Pattern & song editors
  • WAV, YM and SNDH export
  • MP3 export with a supported encoder
Create / SemaPaint

Think in sixteen colours.

Draw on a 320 × 200 ST canvas with ST or STE palettes. Use a subtle tile grid and snap, selections, transforms and undo. Open supported artwork from a game disk and save the edited picture into a separate disk copy.

Demo artwork opened from a real test disk; Save disk copy keeps the original intact.

  • 16-colour pixel artwork
  • Supported disk-art import and copy export
  • Save PI1, NEO and PNG
Create / Maker

Give your picture a life of its own.

Combine a SemaPaint picture, a SemaSynth tune and scrolling text in an ST intro. Save a named project with its picture and music, inspect complete generated assembly, and build a separate floppy image.

An editable intro project using demo artwork.

  • Picture + music + text
  • Generated 68000 source
  • A real ST program on disk
Create / Program Lab

Write for the 68000.

Edit assembly, assemble a program and run it from a disk. Syntax colours, search, undo and saved source files make the desktop a place to build things.

Built-in example program.

  • Assembly editor
  • Built-in assembler
  • Build and run from disk
Explore / Disk Workshop

Get inside the disk.

Browse a disk image, open its files, work with folders and prepare a new ST disk. Move between the workshop and the apps that understand each file.

A demo disk with editable artwork and a README.

  • Browse and manage files
  • Undo edits and save a disk copy
  • Open files in SemaOS apps
Explore / Hardware Check

Ask more of your program.

Run a disk against the available machine configurations and inspect the results. A live test helps you see the program as it runs.

Hardware Check before running a test.
