ENHANCEMENT PROFILES / 1.1.538

Every profile
and its disk.

99 profiles for 75 games. Each profile was made for one particular disk image - the version of the game whose code it knows byte for byte.

Made for lists the disk images (TOSEC names) the profile recognises exactly: there its options are tested. Also recognised lists other versions that carry the same title: SemaTor offers the profile there too, but those builds may differ (another crack, language or revision), so options may not apply or may behave differently. When several versions of a game are in your library, SemaTor starts the one its profile was made for. No game disks come with SemaTor.
