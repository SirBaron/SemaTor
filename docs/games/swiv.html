Keyboard & mouse

Default keyboard joystick mapping: arrow keys move, Left Ctrl fires and Space sends the original Space key. Original game keys remain available.

These are release defaults, not your saved remaps. Open F11 → Controls for this game for live mappings, or F12 → Controls to change them. Start and Back remain reserved for SemaTor menus. Mouse speed is adjustable. One active host gamepad is supported; two-player modes do not imply two simultaneous gamepads.

OPTIONS BY EDITION

Make it your game.

Names match the release profiles, including experimental and practice options. Availability depends on the recognised disk edition. A matching filename alone does not verify an edition; untested releases may behave differently.

SWIV (1991, Storm)

Enhancement

REDUCE DRAWING SLOWDOWN

2x verified sprite, scenery and text pixel loops; reduces drawing stalls; original game clock, sound service and disk streaming

Practice / cheat

KEEP SHOT POWER ON RESPAWN

Retain earned shot count and fire rate when respawning; does not grant upgrades

Practice / cheat

INFINITE LIVES

Preserve both players' life counters when starting their next life

Enhancement

SKIP CRACK INTRO

Continue past this release's Space-key intro gate automatically on the next boot

Practice / cheat

LONGER RESPAWN SHIELD

Double the initial protection after spawning for both vehicles; collected shields and damage rules stay unchanged

Enhancement

STEADY PLAYER DURING SHIELD

Keep the helicopter and jeep visible during protection; removes their on/off flashing without changing shield duration

Enhancement

JEEP JUMP BUTTON

Space (pad X/Y by default) also jumps when using joystick controls; one jump per press; rebind Jump under Controls

Enhancement

DISABLE DOUBLE-TAP JUMP

Stop direction double-taps causing jeep jumps; enable Jump Button for a separate Space/pad jump; keyboard native jump keys still work

Practice / cheat

SPAWN FIREPOWER

Original / Upgraded (4 shots, rate 10) / Maximum (6 shots, rate 8); minimum equipment for the next spawn, never removes stronger equipment

Practice / cheat

MAXIMUM SPAWN FIREPOWER

Six shots and maximum native firing rate on the next spawn; selected through Spawn Firepower

Practice / cheat

QUICKER WEAPON UPGRADES

Matching-colour shot pickups gain two levels up to the native limit; a fire-rate pickup reaches the native fastest rate

Enhancement

ENEMY BULLET OUTLINES

Bright rim around identified standard enemy bullets, with a dark outer edge; original bullet pixels and hitboxes stay unchanged; excludes unmapped special attacks

Practice / cheat

PRACTICE CHECKPOINTS

Save a complete machine checkpoint after spawning; retry through F11 > Saves & rewind > Retry practice checkpoint; manual checkpoints are also available

Enhancement

NATIVE 50 FPS TARGET

50 Hz native movement/drawing target with original 25 Hz decisions and animation; faster verified graphics/asset work; hardware, scrolling and disk clocks retained

Playing on Android or Thor?

Android and dual-screen controls remain in testing. Touch layouts can differ from desktop gamepad defaults. Mega lo Mania’s Thor panel and direct-touch input need device validation; this guide does not certify every touch layout.
