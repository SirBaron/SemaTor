GAME GUIDE / 1.1.544

Fire and Ice

Experimental wider world rendering and native motion interpolation for the ICS release, with original gameplay timing.

Controls and disk change

Joystick moves; up jumps; fire shoots. Gamepad B also jumps by default. Existing saved mappings take precedence. Press Space at the loader. When prompted, insert disk 2 in drive A and press Space or Fire.

Experimental enhancements

Open F12 → Enhancements. Wider World View cycles OFF / 16:9 / 21:9. It reconstructs terrain and active actors from the game world while keeping the original HUD. Original enemy activation, spawning and collision rules remain; unsupported scenes use the original view.

Native Motion Interpolation now samples the scene on a 50 Hz presentation clock, including supported source frames slower than 12.5 FPS. It preserves original physics, input, AI and collision timing. Visual buffering adds about 80 ms at steady 12.5 FPS and can grow during slowdowns. Use a presentation cap of at least 50 FPS at normal speed. Higher refresh rates reuse samples; unsupported scenes fall back and stalled sources are held. This is interpolation, not native 50 Hz gameplay.

1.1.325 fixes native motion dropping back to the original frame rate after a few seconds: each source frame pair is now paced to the measured arrival of the next, which holds across timing differences between the game and your display. Replaying the game’s measured frame cadence at up to ±2% timing difference and 60–240 Hz displays, 93–96% of displayed frames are interpolated. If motion still steps, the session log’s “Fire and Ice motion” lines show why; include them in a report.

1.1.324 timing validation passed 1,050 source pairs across all 35 loader-slot starting fixtures and controlled slowdown/playback cases, at all three aspects. Pause, reload, HUD and repeated-refresh caching were checked. It did not cover timing drift or the game’s irregular cadence, which 1.1.325 corrects.

Both options default off. Native motion takes priority over optical flow for this game; switch it off to use ordinary frame-generation methods. GPU frame-generation methods remain available for the wider view.

1.1.323 validates all 27 distinct map layouts (35 loader slots), including 1,926 full-map grid frames at all three aspects and edge/corner tests. Camera bounds use each map’s actual size. Late terrain changes and stale frames after reloads are fixed. Original enemy activation rules remain. This is controlled rendering validation, not a complete campaign playthrough. Unknown code or unsupported scene layouts automatically fall back.
